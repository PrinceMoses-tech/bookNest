# 📚 BookNext - MERN Book Store App

## 🚀 Tech Stack
- React (Vite)
- Node.js
- Express
- MongoDB
- Context API

## 📂 Project Structure
- frontend → React application
- backend → Express API server

## 🔥 Features
- Browse books
- Add to cart
- Place orders
- User authentication (JWT)
- Order history
